# Календарные аномалии на Московской бирже

Проверка гипотез о том, что доходность российских акций зависит 
от дня недели и месяца — или что видимые различия объясняются 
случайным разбросом.

## Вопросы

1. Отличается ли средняя дневная доходность по дням недели?
2. Есть ли «эффект января»?
3. Устойчивы ли найденные различия во времени?

## Результаты

**Дни недели — эффект есть, но слабый и практически бесполезный.**

Наибольший разрыв: вторник (+0,132% в день) против четверга 
(-0,085%), разница 0,217 п.п.

| проверка | результат |
|---|---|
| t-тест Уэлча (наивный) | p = 0,0069 |
| поправка Бонферрони | p = 0,069 |
| эмпирическая оценка (20 000 симуляций) | p = 0,037 |
| ANOVA по всем пяти дням | F = 2,74, p = 0,027 |
| знаковый тест по годам (11 из 13) | p = 0,023 |

Направление разрыва воспроизводится из года в год, но величина 
скачет от -0,31 до +1,01 п.п. С учётом комиссий (0,05% за сделку) 
от эффекта остаётся 0,075% на сделку — около 3,7% годовых при 
50 сделках, без учёта спреда, проскальзывания и налога.

**Эффект января не подтверждается.**

Январь — лучший месяц (+0,174% против +0,023%), p = 0,0498 — 
ровно на границе. Но результат держится на одном годе: без 
января 2015 (+0,917% в день) p вырастает до 0,213.

## Данные

Дневные котировки 25 ликвидных акций MOEX (режим TQBR), 
2014-2026, источник — MOEX ISS API. 68 804 наблюдения 
после чистки.

## Что пришлось учесть

- **Пропуски**: 452 строки без цены закрытия — остановка торгов 
  в 2022 году и праздничные дни. Удалены, а не заполнены: 
  торгов не было, значит наблюдения не существует.
- **Рабочие субботы**: 9 дней с торгами по переносам выходных 
  (201 наблюдение). Исключены — несопоставимо малая группа 
  с нетипичным режимом торгов.
- **Сплиты**: 5 наблюдений с |доходностью| > 50% — изменения 
  номинала, не движения рынка. Одно из них искажало среднее 
  по всей выборке в 200 раз.
- **Зависимость наблюдений**: 25 бумаг в один день движутся 
  вместе, поэтому расчёт ведётся по схеме «одна дата — одно 
  наблюдение». Это втрое увеличило стандартные ошибки.
- **Множественные сравнения**: пара «вторник-четверг» выбрана 
  после просмотра данных. Симуляция показала, что такая 
  процедура даёт ложную значимость в 29% случаев вместо 5%.

## Ограничения

- Только бумаги, ликвидные на конец периода — ошибка выжившего.
- Девять бумаг начинаются с июня 2014 (перевод на режим Т+2), 
  четыре — недавние размещения. Ранние годы представлены 
  меньшим числом бумаг.
- Расчёт по ценам закрытия; реальное исполнение отличается.
