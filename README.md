# Календарные аномалии на Московской бирже

Проверка гипотезы о том, что доходность российских акций систематически 
зависит от дня недели и месяца — или что видимые различия объясняются 
случайным разбросом.

## Вопрос исследования

1. Отличается ли средняя дневная доходность по дням недели?
2. Есть ли «эффект января» — аномальная доходность в отдельные месяцы?
3. Устойчивы ли найденные различия во времени, или это шум?

## Данные

Дневные котировки акций MOEX (режим TQBR), источник — MOEX ISS API.
Период: 2014-2026. Инструментов: 25.

## Стек

Python, pandas, scipy, statsmodels, matplotlib.

## Структура

- `notebooks/` — ход анализа
- `src/` — переиспользуемые функции
- `data/raw/` — выгрузки с биржи
